# 資料備份

## 為什麼一定要備份

網站的**所有文字與圖片**都存在專案裡的 **`data/` 資料夾**。

這台電腦若損壞、遺失或重灌，**未備份的內容將無法復原** —— 網站上線的版本只是產生出來的網頁，無法還原成可編輯的內容。

> 每次執行 `npm run publish` 後，畫面都會提醒您備份。

---

## 備份

把整個 `data` 資料夾複製到雲端硬碟或隨身碟即可。

**Windows**

```powershell
xcopy /E /I data "D:\備份\heyids200-data-20260101"
```

**Mac / Linux**

```bash
cp -r data ~/備份/heyids200-data-20260101
```

建議在資料夾名稱加上日期，方便分辨版本。

---

## 還原

1. 把備份的資料夾複製回專案中，取代原本的 `data`
2. 執行：

   ```bash
   docker compose restart
   ```

---

## 注意事項

- **此資料夾包含後台密碼**，請勿上傳到公開的網路空間或程式碼儲存庫
- 建議每次做較大幅度的內容調整後備份一次
- 若要換電腦，把 `data` 資料夾一併複製過去即可，內容會完整保留
