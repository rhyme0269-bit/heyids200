# 聯絡表單設定

靜態網站沒有後端可以接收表單，因此訪客送出的諮詢需要交給外部服務處理。以下說明如何用 Google 試算表接收。

---

## 步驟 1：建立試算表

1. 到 [Google 試算表](https://sheets.google.com) 建立一個新檔案，命名為「網站諮詢」
2. 第一列依序填入標題：

   | A | B | C | D | E |
   |---|---|---|---|---|
   | 時間 | 姓名 | 電話 | Email | 諮詢內容 |

---

## 步驟 2：貼上程式碼

在該試算表中點 **擴充功能 → Apps Script**，把預設內容全部刪除，貼上：

```javascript
function doPost(e) {
  try {
    var data = JSON.parse(e.postData.contents);
    var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheets()[0];

    sheet.appendRow([
      new Date(),
      data.name || '',
      data.phone || '',
      data.email || '',
      data.message || ''
    ]);

    // 收到諮詢時寄一封通知信給自己
    MailApp.sendEmail({
      to: Session.getActiveUser().getEmail(),
      subject: '網站收到新的諮詢：' + (data.name || ''),
      body: '姓名：' + (data.name || '') + '\n'
          + '電話：' + (data.phone || '') + '\n'
          + 'Email：' + (data.email || '') + '\n\n'
          + (data.message || '')
    });

    return ContentService
      .createTextOutput(JSON.stringify({ success: true, message: '已收到' }))
      .setMimeType(ContentService.MimeType.JSON);
  } catch (err) {
    return ContentService
      .createTextOutput(JSON.stringify({ success: false, message: '寫入失敗' }))
      .setMimeType(ContentService.MimeType.JSON);
  }
}
```

按上方的儲存圖示。

---

## 步驟 3：部署

1. 右上角 **部署 → 新增部署作業**
2. 齒輪圖示選 **網頁應用程式**
3. 設定：
   - **執行身分**：我
   - **誰可以存取**：**所有人**（這項必須是「所有人」，否則訪客送不出表單）
4. 按 **部署**，首次會要求授權，請一路允許
5. 複製產生的**網頁應用程式網址**（結尾是 `/exec`）

---

## 步驟 4：確認沒有嵌入 Google 表單

**這一步不能跳過，否則後面的設定不會有任何作用。**

後台 → **頁面管理** → 「聯絡我們」→ 編輯 → 「聯絡雙欄」區塊 → 確認「**Google 表單網址**」欄位是**空的**（若有值請清空並儲存）。

只要這個欄位有值，網站就會顯示嵌入的 Google 表單，內建表單完全不會出現，步驟 5 填的收件網址也不會被使用 —— 而且畫面上沒有任何提示。

| 這個欄位 | 訪客看到 | 收件方式 |
|---|---|---|
| 有值 | Google 表單樣式（需登入 Google） | Google 表單 → 試算表 |
| **空的** | 本站表單樣式（不需登入） | Apps Script → 試算表 ＋ 通知信 |

---

## 步驟 5：填入網站設定

後台 →「基本資訊」→「**聯絡表單收件網址**」貼上剛才的網址 → 儲存。

之後執行 `npm run publish` 讓線上網站生效。

---

## 步驟 6：務必實際測試一次

請到線上網站的「聯絡我們」填一筆測試資料送出，然後確認：

1. 畫面上看到的是**姓名／電話／Email／諮詢內容四個欄位**，而不是嵌入的 Google 表單（若是後者，請回到步驟 4）
2. 畫面是否顯示送出成功
3. 試算表是否出現該筆資料
4. 是否收到通知信

### 若資料進了試算表，但畫面顯示「送出失敗」

這種情況是**瀏覽器的安全限制**造成的，資料其實有收到，但網站無法讀取回應、因而無法確認成功。

我們不會讓網站在無法確認的情況下顯示「已送出」—— 那會讓訪客以為已聯繫上，實際上可能沒有。

**若出現這個情況，請告知我們**，我們會改用另一種收件服務（設定同樣簡單，且能確實回報成功與否）。

---

## 沒有設定收件網址會怎樣

- **本機編輯時**：表單改用站內功能，可正常測試
- **線上網站**：訪客送出時會顯示錯誤，並提示改用電話或 LINE 聯繫

因此正式上線前請務必完成本文件的設定。

---

## 防止廣告訊息

公開的收件網址可能收到廣告訊息。若量大到造成困擾，請告知我們，可加上驗證機制。
