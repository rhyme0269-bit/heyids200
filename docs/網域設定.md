# 網域設定

把自己租的網域指向網站，並啟用 HTTPS 加密。

以下以 `example.com.tw` 為例，請換成您的網域。指令請在專案資料夾中執行。

---

## 完成後的效果

- 訪客輸入 `https://example.com.tw` 就會看到網站
- 網址列出現鎖頭圖示（連線已加密）
- **憑證由 GitHub 自動更新，不會過期，不需要手動處理**

---

## 步驟 1：填入網址

編輯 `.env`：

```env
NEXT_PUBLIC_SITE_URL=https://example.com.tw
```

---

## 步驟 2：設定 DNS

登入您的網域商後台（Gandi、GoDaddy、PChome 網路家庭、中華電信等），新增以下記錄：

| 類型 | 名稱 | 值 |
|---|---|---|
| A | `@` | `185.199.108.153` |
| A | `@` | `185.199.109.153` |
| A | `@` | `185.199.110.153` |
| A | `@` | `185.199.111.153` |
| CNAME | `www` | `rhyme0269-bit.github.io` |

**四筆 A 記錄都要新增**，這是 GitHub 的固定位址。

設定後需等待生效，通常幾分鐘、最長可能數小時。

---

## 步驟 3：發布一次

```bash
npm run publish
```

這一步會建立 `gh-pages` 分支，下一步才會出現對應選項。發布指令也會自動產生綁定網域所需的 `CNAME` 檔，不需手動建立。

---

## 步驟 4：在 GitHub 設定

到儲存庫頁面 → **Settings** → **Pages**：

1. **Source** 選 `Deploy from a branch`
2. 分支選 **`gh-pages`**，資料夾選 `/ (root)`，按 **Save**
3. **Custom domain** 填入您的網域，按 **Save**
4. 等憑證簽發完成（通常幾分鐘），勾選 **Enforce HTTPS**

> ⚠️ **分支必須選 `gh-pages`**。
> `main` 存放的是程式原始碼，不是網頁檔案。若選成 `main`，即使 DNS 設定正確，網站也不會正常顯示。

---

## 上線後建議一併處理

到 [Google Search Console](https://search.google.com/search-console) 提交網站與 `https://example.com.tw/sitemap.xml`，可加快被搜尋到的速度，也能觀察關鍵字成效。

---

## 確認是否生效

```bash
nslookup example.com.tw
```

若顯示上面那四組 GitHub 位址之一，表示 DNS 已生效。

若網站仍打不開，請見 [疑難排解](疑難排解.md)。
